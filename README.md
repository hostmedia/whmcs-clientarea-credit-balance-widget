# WHMCS Clientarea Credit Balance Widget (Panel)

This widget/panel provides a client area panel with your customers available credit balance with quick links to add further funds. 

## Installation
* Download the latest master (Direct Download Link: https://github.com/hostmedia/whmcs-clientarea-credit-balance-widget/archive/refs/heads/main.zip)
* Upload to your WHMCS install, if you are uploading just 'clientCreditWidget.php' make sure to upload it to: /WHMCS-Directory/includes/hooks/

## WHMCS Tested Versions
* 8.0 - 8.8
* 7.10
